# Instructor dashboard

Open `/instructor-dashboard/instructor_dashboard/instructor_dashboard.php` through the project web server after signing in with an instructor account.

The instructor workspace includes:

- Overview metrics, student activity, and upcoming tasks
- Instructor-owned course list, course creation, and analytics
- Student roster, performance views, and private messaging
- Assignment creation, submissions, and grading
- Course announcements and discussion messages
- Schedule, reports, profile, password, appearance, and notification preferences
- Responsive collapsible sidebar, searchable/sortable tables, theme toggle, and confirmation modal

The dashboard uses the existing project database connection and the `courses`, `enrollments`, `assignments`, `assignment_submissions`, `messages`, and `announcements` tables. External fonts, Bootstrap, icons, and Chart.js are loaded from CDNs.
