# Admin dashboard

Open `/Admin-dashboard/Admin_dashboard/Admin_dashboard.php` through the project web server after signing in with an administrator account.

The workspace includes account management, student and instructor directories, course management and analytics, enrollment reports, announcements, messaging, audit logs, account settings, security activity, and system status tools. The shared interface provides a responsive grouped sidebar, mobile navigation, searchable and sortable tables, edit dialogs, CSRF-protected mutations, and confirmation dialogs for destructive actions.

Reports use the project’s payments and enrollments tables. The maintenance screen is only an admin-session preview because there is no global maintenance configuration. A database backup service is not configured; use the hosting provider’s restricted backup tooling.
