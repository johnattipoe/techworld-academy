# User Management Guide

## Overview
The User Management page allows admins to view, add, edit, and remove users, assign roles, and monitor user activity.

## Features
- View all users
- Add new users
- Edit user details
- Assign roles (admin, instructor, student)
- Remove users
- Error alerts for failed actions
- Audit log tracks all user management actions

## Tips
- Use search to quickly find users
- Review audit logs for user changes
- Check error alerts for failed actions
